IPTC photo metadata tests

Media and imagestest serieshistorical
IPTC photo metadata tests: a test series. Operator: IPTC (International Press Telecommunications Council), Photo Metadata Working Group. The object it attaches provenance to: the photograph as a file: embedded Exif and IPTC metadata (IIM and XMP).
Visit IPTC photo metadata tests ↗Run an erasure audit
IPTC promotes the proper use of IPTC Photo Metadata and claims “embedded metadata should not be removed” from images shared on a photo platform or a system for sharing files or messages with images.

In its own words: https://iptc.org/standards/photo-metadata/social-media-sites-photo-metadata-test-results-2019/, read 2026-10-29

Operations testedupload to a sharing site or system; display to a viewer; Save As from the browser; download through the system op
What survived2019: of eleven image-sharing sites, Pexels, pixabay and Unsplash stripped metadata from saved and downloaded files; Flickr replaced the embedded creator with the account owner; Flickr's saved files had no XMP, EyeEm's no Exif and Google Photo's no IPTC IIM; Behance's saved files kept the embedded metadata; among file and message systems Twitter stripped it on Save As, Dropbox and Microsoft OneDrive previews saved with the metadata stripped, Facebook kept a few rights fields in IIM and Exif op
